Política de Privacidade

O Melodia é um projeto acadêmico demonstrativo desenvolvido para o Checkpoint 5 de Front-End da FIAP. O formulário presente nesta página não realiza cadastros em serviços externos nem envia informações para servidores.

Dados informados

O formulário solicita nome, endereço de e-mail e, opcionalmente, estilo musical favorito. Esses dados são utilizados exclusivamente para demonstrar o funcionamento da interface.

Armazenamento

Os dados preenchidos são armazenados localmente no navegador por meio da API localStorage. Nenhuma informação é enviada para servidores ou serviços de terceiros pelo formulário demonstrativo.

Exclusão dos dados

As informações armazenadas localmente podem ser removidas por meio da limpeza dos dados deste site nas configurações do navegador.

Finalidade acadêmica

O projeto não oferece assinatura, cadastro comercial, campanhas de marketing ou envio automático de e-mails. As funcionalidades apresentadas têm caráter demonstrativo e educacional.

Para testar o formulário, recomendamos utilizar informações fictícias e evitar o preenchimento com dados pessoais reais.
